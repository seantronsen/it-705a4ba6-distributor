## Harness bugs fixed during the run (suite code only)

1. `run-integration-test` load_config: `[[ -v ]] && declare -p` as the loop's last command made
   `set -e` exit silently; environment overrides were also restored as locals (`declare -g` now).
2. `run-integration-test` pick_engine: ended in `[[ docker ]] && ...`, returned 1 on podman,
   silent exit.
3. `lib/repos.sh` wipe: listing tags on an empty repo returns 409 with JSON on stdout; the loop
   tried to delete the JSON words. Tags are skipped on empty repos.
4. `lib/poll.sh` dispatch_poll and case 14: newer `gh workflow run` prints the run URL on stdout,
   corrupting the captured run id. Output discarded.
5. `lib/poll.sh` state_has: took the jq filter first; every caller passes it last. Case 02 failed
   on this in the full run.

Also changed before the run: the guard no longer requires `it-*` names, and case 12 skips its
longer-name check (with a log line) when the second repo's name doesn't start with the testbed's.
